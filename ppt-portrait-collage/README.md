# PPT Portrait Collage（PPT 人物拼贴页 Skill）

> 把多张人物照片，做成一页「彩色主图 + 半透明淡彩碎片墙 + 渐变氛围底 + 手写金句破版」的高级感人物介绍 PPT 页面（16:9 横版）。

适用于 AI 助手（如豆包等支持 Skill 机制的智能体）的人物介绍页生成任务。用户上传多张人物照片后，本 Skill 指导模型完成**主图抠像 → 色彩派生 → 碎片拼贴 → 文字排版**的完整设计流程，输出一张可直接用于 PPT 的横版页面。

---

## ✨ 核心视觉法则

一张成功的拼贴页，靠的是**清晰度、饱和度、不透明度**三重差距让主角跳出来：

| 元素 | 处理方式 |
|---|---|
| 主图抠像（1 张） | **保留原始全彩**，全页最清晰、最饱和、最大，悬浮在背景上（不是矩形框） |
| 碎片照片（N 张） | **低饱和 + 半透明淡彩色**（40–50% 不透明度），边缘羽化渐隐，退到主图后面当装饰 |
| 空色块（1–2 块） | 主图主色的极淡版本，作为视觉呼吸点 |
| 背景渐变 | 从**主图主色派生**（降饱和 + 提亮）渐变到白色，不凭空选色 |
| 手写金句 | **深炭黑色**，斜向约 15° 压在主图下半身，故意破版 |

> ⚠️ 实战踩坑：碎片**不要做成纯黑白灰度**——会灰蒙蒙像丧图；也不要高饱和全彩——会抢主图风头。半透明淡彩色才有时尚杂志拼贴感。

## 🚀 安装

将整个 `ppt-portrait-collage` 文件夹放入你的 Skill 根目录即可，例如：

```bash
# 豆包/支持 Skill 机制的智能体
cp -r ppt-portrait-collage ~/.doubao/agent_mode/workspace/.user_skills/
```

安装后重启会话，当用户请求「把这几张照片做一页人物介绍 PPT」「追星相册做高级感拼贴页」时，Skill 会自动匹配生效。

## 🧭 使用流程

1. **定主图**：从用户上传的照片中选出主角（最新上传 / 尺寸最大 / 最正脸，或按用户指定）；若 ≥3 张且未指定，先与用户确认。
2. **提取主色**：读取主图，判断 dominant color，派生出背景渐变的淡色版本。
3. **收集文案**：人物姓名（左下角）、一句话简介、右下角标语（含英文对照）、中部手写金句（≤25 字）。
4. **决定版式**：根据人物朝向放置主图（脸朝右→偏左；脸朝左→偏右；正面→居中）。
5. **调用出图工具**：有参考照片用 `image_edit`（主图放第 1 位），无照片用 `image_gen`；统一 `width=2048, height=1152`（16:9），`model_version=seedream_5.0_flash`。
6. **自检返工**：按 SKILL.md 的 7 条清单核对主图焦点、碎片处理、金句颜色、文字可读性。

## ✅ 输出规格

- **画幅**：16:9 横版，2048 × 1152 px
- **字体**：整页 ≤ 3 种（粗黑体姓名/标语、常规黑体简介、手写体金句），最小字号 ≥ 28px
- **主图**：抠像 cutout，只去背景，不重画脸、不美颜、不改五官发型服装
- **去重**：每张用户上传的参考图只用一次，不重复、不遗漏

## ❓ 常见问题

**Q：为什么碎片不用纯黑白？**
纯黑白会让整面灰扑扑、像追悼会海报。保留低饱和彩色 + 40–50% 透明度，更有高级感和层次。

**Q：金句为什么必须深炭黑？**
金句压在主图下半身，如果用主图主色（如红色衣服配红字）会糊成一团，深炭黑才能保证可读性和破版冲击力。

**Q：碎片排成整齐矩阵怎么办？**
在 prompt 里加重申「矩形大小不一、错位排列、不对齐」。
