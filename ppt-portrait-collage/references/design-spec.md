# 设计规范（Design Spec）

本 skill 的所有版式、色彩、字体规则都收在这里。出 prompt 之前必须对照本表。

## 一、网格骨架

底层结构是 **7 列 × 3 行 = 21 个等大矩形格**，但这只是占位参考，最终不出现整齐矩阵：

- **主图**：**抠像 cutout**（不是矩形框里的照片），人物从原背景里完整切出，悬浮在渐变背景之上，居中或居中偏左/偏右。
- **碎片框**：剩下的格子里，挑 N 个（N = 用户上传的辅助照片数）拉成大小不一的矩形（有小方形、有横长条、有竖长条），互相错位。
- **空色块**：留 1–2 个格子**不插图**，填一个比背景略深/略浅的同色系纯色块，作为视觉呼吸点。

节奏口诀：**一个抠像主角 + N 张矩形碎片 + 一两块空色**。塞满会像证件照墙，太疏会像拼贴失败。

## 二、色彩层级（最重要）

| 元素 | 颜色处理 |
|---|---|
| 主图抠像（1 张） | **保留原始全彩**，是全页最清晰、最饱和、最大的视觉焦点 |
| 碎片图（N 张） | **低饱和 + 半透明淡彩色**（约 40–50% 不透明度），边缘羽化渐隐融入背景（不要硬方框），隐约能看出原色但退到背景里当装饰，不要纯黑白 |
| 空色块（1–2 块） | 主图主色的极淡版本（比背景深 5–10%） |
| 背景 | 主图主色的极淡版本渐变到白 |
| 姓名/简介/标语 | 纯黑或深灰 |
| **手写金句** | **深炭黑色（#1a1a1a 感）**，不要用主图主色 |

原理：主图是"全彩+全不透明+最大"，碎片是"低饱和+半透明+小"，通过**清晰度、饱和度、不透明度**三重差距让主图跳出来，而不是靠把碎片做成纯黑白——纯黑白会让碎片墙显得灰蒙蒙、像丧图，半透明淡彩色更高级、更像时尚杂志拼贴。

### ⚠️ 为什么碎片不用纯黑白（实战踩坑）

早期版本要求碎片全部转黑白灰度，实战发现：
- 整面灰扑扑的，像追悼会海报，不像追星/冠军页
- 纯黑白碎片和淡色背景之间缺乏层次，看起来"脏"
- 用户反馈"灰色有点太重了，保留一部分彩色加透明度更好"

**结论**：碎片保留原本的低饱和彩色，但降到 40–50% 不透明度，像淡淡的残影退到主图后面。隐约能看出原色（红衣、蓝衣、紫背心等），但绝对不抢主图风头。同时碎片矩形的边缘要**羽化渐隐**，柔和地融入背景，不要锐利的硬方框边——硬边会让碎片像贴上去的贴纸，羽化后才像淡淡的光斑晕染在背景上。

## 三、背景取色派生规则

从主图主色派生背景，三步：

1. **识别主色**：看主图里占面积最大 / 最饱和的那个颜色。
   - 天蓝、湖蓝、深蓝 → 冷蓝系
   - 橙红、夕阳、暖黄、舞台红 → 暖橙红系
   - 墨绿、森绿、青灰 → 灰绿系
   - 粉紫、玫瑰 → 粉紫系
   - 黑白照片、灰调、低饱和 → 中性灰系
2. **降饱和 + 提亮**：把主色饱和度降到原来的 20–30%，明度提到 90%+，得到背景起始色。
3. **渐变方向**：默认从左上角 / 左下角斜向渐变到对角白色，不要纯平涂。

示例对应：

| 主图主色 | 背景渐变 |
|---|---|
| 天蓝（户外、晴天、运动） | 极淡蓝 → 白 |
| 正红（舞台、红衣、红毯） | 极淡玫瑰粉 → 奶白 |
| 暖橙（夕阳、暖色灯光） | 极淡杏橙 → 米白 |
| 墨绿（山林、户外徒步） | 极淡灰绿 → 白 |
| 粉紫（樱花、柔光灯） | 极淡粉紫 → 白 |
| 冷灰（雪山、都市、黑白质感） | 极冷灰 → 白 |

## 四、照片保真与去重（实战硬规矩）

1. **每张参考图只用一次**：用户上传了 N 张辅助照片，碎片墙就用 N 个矩形，每张参考图对应一个矩形，不要重复使用同一张图，也不要漏掉任何一张。prompt 里逐个指定位置。
2. **不要 AI 重画脸**：碎片照片就是用户给的原图做低饱和半透明处理，不是让 AI 重新画一个"同风格人物"。
3. **不要遮挡面部**：碎片矩形里的人物脸要完整露出。
4. **主图抠像保留原脸**：主图 cutout 时只去背景，不改五官、不美颜、不变形、不换发型。

## 五、字体层级

整页不超过 3 种字体，分工明确：

| 层级 | 内容 | 字体感觉 | 位置 | 字号相对大小 |
|---|---|---|---|---|
| 姓名 | 人物姓名 | 粗黑无衬线，重 | 左下角 | 大 |
| 简介 | 2–3 行人物 slogan | 常规无衬线，深灰 | 姓名正下方 | 小 |
| 标语 | 右下角粗体词 + 英文对照 | 粗黑无衬线，重 | 右下角 | 中→大 |
| 手写金句 | 斜向一句话 | **手写毛笔感，深炭黑色** | 中部偏下，压在主图下半身 | 大（视觉冲击） |

手写金句是唯一允许"破版"的元素：
- 故意压在主图身上，不要留边距。
- 故意倾斜 10–20 度，不要水平对齐。
- 故意突破矩形碎片的边界。
- 颜色永远是深炭黑，不要彩色。

## 六、主图位置选择

| 主图人物朝向 | 主图位置 |
|---|---|
| 脸朝右 | 居中偏左 |
| 脸朝左 | 居中偏右 |
| 正面看镜头 | 居中（用户说"居中突出"时直接放正中） |
| 背影/侧影 | 居中偏左，碎片围住 |

## 七、不要做的事

- 不要给主图加白色边框、阴影、圆角。
- **不要把碎片做成纯黑白灰度**——要低饱和半透明淡彩色，灰蒙蒙的像丧图。
- 不要把碎片做成高饱和全彩——会和主图抢风头。
- 不要用超过 3 个字体家族。
- 不要把手写金句写成红/蓝/绿等彩色——一律深炭黑。
- 不要让同一张参考图在碎片墙里出现两次。
- 不要让 AI 重画人脸。
- 不要把人物姓名做成大标题居顶。
