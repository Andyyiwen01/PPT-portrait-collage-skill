# Prompt 配方（Prompt Recipe）

给 `image_edit`（有参考照片时）或 `image_gen`（无参考照片时）的 prompt 结构。每次出图前照着骨架填占位符。

## 通用骨架

```
一张 16:9 横版 PPT 人物介绍页，高级时尚杂志拼贴海报感。

【背景】全屏从 [主色派生淡色] 渐变到奶白色，干净通透。

【主图抠像】画面 [居中/居中偏左/居中偏右]，把第 1 张参考图（[描述主图人物造型]）完整抠像去背景，像剪纸一样从原背景里干净切出来，悬浮在渐变背景之上，不带任何原背景色块。人物必须原原本本保留：五官、脸型、发型、服装、道具都不要改、不要重画、不要美颜、不要变形。这是全页最清晰、最饱和、最大的视觉焦点。

【碎片照片墙】主图周围错落贴 [N] 张矩形照片，每张参考图只用一次，不重复：
- [位置 1]：参考图 [i]（[造型描述]）
- [位置 2]：参考图 [j]（[造型描述]）
- ……
这些碎片照片统一做【低饱和 + 半透明淡彩色】处理：保留原本的低饱和度彩色（隐约能看出红衣、蓝衣等原色），但整体透明度降到约 40–50%，像淡淡的半透明装饰背景一样退到主图后面，不抢眼、不跳出来。碎片矩形的边缘做羽化渐隐处理，柔和地融入背景，不要锐利的硬方框边。不要纯黑白灰度（灰蒙蒙像丧图），也不要高饱和全彩（会抢主图风头）。矩形大小不一、错位排列不对齐。人物面部保持参考图原样，不修改、不遮挡。留 1–2 个极淡主色块空位呼吸。

【文字】
- 左下角：粗黑无衬线体大号名字"[人物姓名]"，名字下方两行小字简介"[一句话简介]"。
- 右下角：粗黑无衬线体标语"[标语大字]"，下方配小号英文"[English Tagline]"。
- 画面中部偏下，斜向约 15 度手写毛笔感大字金句，颜色深炭黑色（接近墨色，不要彩色），内容是"[手写金句]"，故意压在主图下半身，突破周围矩形照片边界。

【硬约束】
- 主图人物忠实于第 1 张参考图，不重画脸、不美颜。
- 碎片照片分别对应其余参考图，每张只出现一次，不重复、不遗漏。
- 主图是全页最清晰最饱和的；碎片是低饱和半透明淡彩色，退在后面。
- 手写金句颜色深炭黑色，不是彩色。
- 字体不超过 3 种。
- 所有文字清晰可读，简体中文，无乱码无伪文字。
- 所有元素在画布边界内。
```

## 调用方式

### 有用户上传的参考照片时（推荐路径）

用 `image_edit`：
- `image_reference_url_list`：**把主图放第 1 位**，其余碎片图按 prompt 里指定的顺序排后面。
- `width=2048, height=1152`，`model_version=seedream_5.0_flash`。

### 没有参考照片时

用 `image_gen`：prompt 同上但不挂参考图，主图描述写清楚人物性别、年龄段、穿着气质。

## 完整正例（实战验证过）

```
一张 16:9 横版 PPT 人物介绍页，高级运动时尚杂志拼贴海报感。

【背景】全屏从极淡玫瑰粉米色渐变到奶白色。

【主图抠像】画面正中央，把第 1 张参考图（穿红色无袖运动衣、扎马尾、仰拍脸部特写、脸上有汗珠、坚毅抬头的女性网球运动员）完整抠像去背景，悬浮在渐变背景上。人物原原本本保留：五官、红色运动衣、汗珠、项链都不要改。这是全页最清晰最饱和的视觉焦点。

【碎片照片墙】主图周围贴 7 张矩形照片，每张参考图只用一次：
- 左上：参考图 2（正手击球蓝色球拍）
- 中上：参考图 3（发球击球黑背景）
- 左中：参考图 4（举球拍庆祝观众席）
- 右上：参考图 5（蓝色运动背心长发特写）
- 右中：参考图 6（蓝色硬地场发球）
- 右下：参考图 7（粉色运动背心竖大拇指）
- 最右下：参考图 8（发球后站姿蓝色场地）
碎片统一做低饱和半透明淡彩色处理（约 40-50% 不透明度），隐约能看到原色但退到主图后面，不要纯黑白，不要高饱和。留 1 个极淡玫瑰粉色块空位。

【文字】左下"郑钦文 / 中国网球运动员 WTA CHAMPION"；右下"网球冠军的追梦路 / THE ROAD TO A CHAMPION"；中部斜向深炭黑手写金句"郑式登场，迎万难，赢万难"。
```

## 常见失败反例

| 失败现象 | 说明 | 返工怎么改 |
|---|---|---|
| 碎片是纯黑白灰度 | 灰蒙蒙像丧图 | 加"碎片保留低饱和彩色，半透明 40-50%，不要纯黑白" |
| 碎片是高饱和全彩 | 和主图抢风头 | 加"碎片降饱和度，半透明，退到后面" |
| 金句颜色和主图衣服撞色 | 糊在一起 | 强制写"金句深炭黑色" |
| 同一张参考图用了两次 | 重复浪费素材 | 逐个指定位置，加"每张只用一次" |
| AI 重画了新脸 | 不像本人 | 加"不重画脸，忠实于参考图" |
| 主图没抠干净 | 还带原背景 | 加"人物完整切出，不带原背景色块" |
| 碎片排成整齐矩阵 | 失去拼贴感 | 加"矩形大小不一、错位排列" |
| 文字乱码 | AI 文字问题 | 缩短文字重新生成 |
