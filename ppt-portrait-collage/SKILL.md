# PPT 人物拼贴页（Portrait Collage）

把用户上传的多张人物照片，做成一页"彩色主图 + 黑白碎片墙 + 渐变氛围底 + 手写金句破版"的高级感人物介绍 PPT 页面。

## 硬性约束（不可违背）

- **画幅**：16:9 横版，调用出图工具时 `width=2048, height=1152`。
- **主图是视觉焦点**：主图抠像后是全页**最清晰、最饱和、最大**的人物；周围碎片是**低饱和 + 半透明淡彩色**（约 40–50% 不透明度），边缘羽化渐隐融入背景（不要硬方框），隐约保留原色但退到后面当装饰。**不要把碎片做成纯黑白灰度**（灰蒙蒙像丧图），也不要高饱和全彩（会抢主图风头）。
- **主图是抠像 cutout**：主图从原照片背景里完整切出，悬浮在渐变背景之上，**不是**矩形框里的照片。只去背景，不重画脸、不美颜、不改五官发型服装。
- **背景随主图走**：背景渐变色必须从主图主色调派生（降饱和 + 提高明度的淡版本），不要凭空选色。
- **手写金句破版，颜色永远深炭黑**：中部压一句斜向手写体金句，**颜色一律用深炭黑色（接近墨色），不要用主图主色**——因为金句要压在主图下半身，红衣配红字会糊成一团。
- **碎片照片保真去重**：碎片墙每张用户上传的参考图只用一次，不重复、不遗漏；不让 AI 重画人物造型、不遮挡面部。
- **文字层级**：整页字体 ≤ 3 种（粗黑体名字+标语、常规黑体简介、手写体金句），最小字号在 2048 宽画布下 ≥ 28px，不出现乱码伪文字。

## 工作流

### 第 1 步：盘点用户上传的照片，定主图

用户可能上传 1 张或多张人物照片。

- **多张照片**：默认把用户最新上传、或尺寸最大、或人物最正脸的那张作为**主图**（全彩保留）；其余全部作为**碎片图**（低饱和半透明淡彩色处理）。如果用户明确指定了哪张是主角，按用户说的来。
- **只上传 1 张**：主图就是这张，碎片位置用同人物不同角度的半透明淡彩色小占位照补齐。
- **没上传照片、只给文字描述**：纯文生图，prompt 里描述一个通用的人物拼贴墙，人物形象按用户描述走。

**如果用户上传了 ≥ 3 张照片但没说哪张是主角，先用一句话确认："哪张做主图（保留彩色那张）？"再继续。**

### 第 2 步：从主图提取主色调

Read 主图（参考图模式，大图看清），用一句话判断：

- 主图 dominant color 是冷蓝 / 暖橙红 / 灰绿 / 粉紫 / 黑白灰 / 其他？
- 这个颜色派生的**淡版本**（降饱和 60% + 提亮 80%）作为背景渐变起始色，渐变到白色。
- **手写金句颜色不用管主图主色，一律用深炭黑色**（避免和主图衣服撞色）。

把这个色感写进草稿，例如："主图正红 → 背景极淡玫瑰粉渐变 + 手写体深炭黑"。

### 第 3 步：收集文字素材

向用户要齐（没给就用合理占位，并在交付时提示用户替换）：

1. **人物姓名**（左下角粗体，如"张某人"）
2. **一句话简介**（名字下方小字 2–3 行，如"十年深耕，始终如一"）
3. **右下角标语**（粗黑体 + 英文对照，如"初心不改 / KEEP GOING"）
4. **手写金句**（斜向压在画面中部的一句最能代表人物气质的话，不超过 25 字）

不要自己编造人物事迹/奖项/头衔，用户没给就空着或用占位。

### 第 4 步：决定版式

按 `references/design-spec.md` 的版式表选：

- 主图默认**居中**（用户说"居中突出"时），或根据人物朝向偏左/偏右。
- 碎片数量 = 用户上传的辅助照片数（每张用一次），外加 1–2 个纯色块空位形成呼吸节奏。
- 主图位置可根据人物朝向调整：脸朝右→主图偏左；脸朝左→主图偏右；用户说"居中"就放正中。

### 第 5 步：调用出图工具

- **有参考照片时**：用 `image_edit`，把所有用户上传的照片 URL 放进 `image_reference_url_list`，按 `references/prompt-recipe.md` 的配方拼 prompt。
- **无参考照片时**：用 `image_gen`，prompt 同上但不挂参考图。

调用参数统一：`model_version=seedream_5.0_flash`，`width=2048, height=1152`。

### 第 6 步：自检与返工

出图后按这个清单核对，任何一条不过就在 prompt 里加重申后重新生成：

1. 主图是全页最清晰最饱和的视觉焦点，碎片是低饱和半透明淡彩色（不是纯黑白，也不是高饱和全彩）。
2. 背景渐变颜色和主图主色是同一淡色系，不是打架的对比色。
3. 主图是抠像 cutout 悬浮在背景上，不是矩形框；人物五官和参考图一致，没被 AI 重画。
4. 碎片矩形大小不一、错落排列，不是整齐矩阵；每张参考图只用了一次，没重复没遗漏。
5. 左下角有姓名+简介，右下角有粗体标语，中部有斜向手写体金句。
6. **手写金句是深炭黑色**，不是彩色，不和主图衣服撞色。
7. 文字无乱码、无溢出画布、无伪文字。

## 交付

出图后直接把图片展示给用户，用 2–3 行字说明：选了哪张做主图、从主图派生了什么色系、文字里有哪些是占位需要用户替换。不要附冗长的设计说明。
